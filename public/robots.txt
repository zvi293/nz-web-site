# Everything is crawlable. Pages that must stay out of the index (/thank-you/, the 404 page) say so
# with <meta name="robots" content="noindex, follow">: they are deliberately NOT disallowed here,
# because a crawler that may not fetch a page never sees its noindex (Google: a blocked URL can
# still be indexed from links, without content). scripts/qa/site-qa.mjs fails the build check if a
# noindex page is ever disallowed again.
#
# Content signals (https://contentsignals.org) for every crawler below:
#   Content-Signal: search=yes, ai-input=yes, ai-train=yes
# It is stated here as a comment on purpose: as a directive line it is not part of RFC 9309, so
# Lighthouse / PageSpeed mark robots.txt "not valid" (SEO 92 on every page). "yes" grants nothing
# beyond "Allow: /", which every group already has, so nothing is lost.
# A crawler obeys only its most specific group (RFC 9309), so every named group repeats the rules
# instead of inheriting them from "*".
